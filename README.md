# Aster-Launcher
Fast, Seek, Neutral, Modular, Cross-Platform Minecraft Launcher with Rust

Fast:GPUIとRustによりネイティブコンパイルされ、wasmにより拡張されます。
Seek:バンドルPluginをオフにすれば無駄な機能は非表示になります。膨大な設定項目に圧倒されません。
Neutral:特定の政治的団体を支持したり、金儲けのために広告を導入しません。使用してくれる全ての人を尊重します。
Modular:全てはPluginです。ないと思った機能は追加可能です。好きな認証サーバー、好きなModloader、好きなMod配布サイト、あなたの必要な全てを追加してください。
Cross-Platform:Linux、Windows、macOSをサポートします。
Not Only Minecraft:将来的にMinecraftのRust再実装であるHorizonをサポート予定です。
